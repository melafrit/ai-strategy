Ce canvas accompagne l'activité pratique du Module 1. Quatre étapes
structurées, ~30 à 60 minutes en autonomie ou en atelier de petit
groupe. Imprimable au format A4 paysage si nécessaire.

Marquez chaque processus comme candidat IA `fort` / `moyen` / `faible`.

## Étape 4 — Évaluer le ratio valeur / risque

Notez chaque candidat retenu sur 5 dimensions, échelle de 1 (faible) à 5 (fort).

| Candidat | Valeur business attendue | Faisabilité (données + intégration) | Risque éthique / réglementaire | Maturité organisationnelle | Score net (V × F − R × M) |
|:---------|:-------------------------:|:------------------------------------:|:--------------------------------:|:----------------------------:|:--------------------------:|
| A        |                           |                                      |                                  |                              |                            |
| B        |                           |                                      |                                  |                              |                            |
| C        |                           |                                      |                                  |                              |                            |

**Légende** :
- **V** = Valeur business (1-5) si le projet réussit
- **F** = Faisabilité (1-5) — qualité données, intégration, conduite du changement
- **R** = Risque éthique/réglementaire (1-5) — biais, vie privée, conformité (AI Act, RGPD)
- **M** = Maturité organisationnelle (1-5) — capacité de l'organisation à porter le projet

**Le candidat à privilégier en pilote** = celui qui maximise V × F
en gardant R × M sous contrôle.

## Critères de qualité — auto-évaluation

Avant de présenter votre cadrage à un dirigeant ou un client, vérifiez :

- ☐ Les processus listés couvrent au moins deux fonctions différentes.
- ☐ Chaque candidat IA est rattaché explicitement à une dimension stratégique.
- ☐ L'évaluation valeur/risque est explicite et défendable devant un COMEX.
- ☐ Le candidat retenu peut être défendu en moins de 90 secondes oralement.

Si l'une de ces cases reste vide, reprenez l'étape correspondante
avant de présenter le cadrage.
