## Étape 2 — Choisir la famille robotique

**Type de robot pressenti** (cocher) :

- ☐ **Robot industriel classique** (ISO 10218)
  - *Cellule grillagée, isolation des humains, performances brutes (vitesse, charge, précision)*
  - *Adapté à : production en série, environnement structuré, volumes très importants*
- ☐ **Robot collaboratif / cobot** (ISO/TS 15066)
  - *Conçu pour partager l'espace humain, capteurs de force, vitesses limitées*
  - *Adapté à : montage assisté, postes mixtes humain-machine, PME, reconfigurabilité*
- ☐ **Robot mobile autonome (AMR/AGV)**
  - *Transport de charges en atelier ou entrepôt, navigation autonome*
  - *Adapté à : logistique, intralogistique, environnements changeants*

## Étape 3 — Analyser la sécurité et l'intégration

### A. Sécurité humain-machine

**Cadre normatif applicable** (cocher) :
- ☐ ISO 10218 (robots industriels)
- ☐ ISO/TS 15066 (cobots — coexistence avec humain)
- ☐ Directive Machines 2006/42/CE
- ☐ Réglementation sectorielle spécifique : _____________________

**Exigences de sécurité à anticiper** :
- ☐ Analyse de risque formelle (par l'intégrateur, contre-expertise interne)
- ☐ Mesure de force / vitesse / zones de contact (cobots)
- ☐ Dispositifs d'arrêt d'urgence accessibles
- ☐ Formation et certification des opérateurs
- ☐ Procédures d'incident, signalement, retour d'expérience
- ☐ Maintenance préventive avec contrôle de sécurité périodique

**Critère de qualité** : si moins de 4 cases sont cochées, le projet
n'est pas prêt à être déployé.

**Règles pratiques** :
- Si le robot représente plus de 50 % du total → l'intégration est
  probablement sous-estimée (norme : robot 30-50 %, intégration 50-70 %)
- Si la formation est à zéro → c'est probablement une omission

### B. Gains attendus (par an, en production stabilisée)

| Mécanisme | Estimation €/an |
|:----------|:---------------:|
| Productivité (volumes traités, cadence) |  |
| Qualité (réduction des rebuts, des reprises) |  |
| Conditions de travail (TMS évités, accidents évités) |  |
| Flexibilité (reconfiguration possible) |  |
| Réduction de main-d'œuvre directe (préciser : redéploiement vs suppression) |  |
| **Total Gains €/an** |  |

**Note importante** : si le seul gain est la « réduction de masse
salariale », le projet est fragile socialement et juridiquement.
Privilégier les gains combinés (ergonomie + qualité + productivité).

### C. Payback

**Payback estimé** = Investissement / Gains €/an = __ années

- ☐ Payback < 18 mois → cas exceptionnel, à valider en POC
- ☐ Payback 18-36 mois → typique d'un projet bien cadré
- ☐ Payback 36-60 mois → projet défendable si ergonomie / qualité forts
- ☐ Payback > 60 mois → revoir le périmètre ou l'ambition

## Critères de qualité — auto-évaluation

Avant de présenter le projet à un dirigeant, un IRP ou un client,
vérifiez :

- ☐ Le poste candidat est décrit précisément (qui, quoi, combien).
- ☐ La famille robotique est choisie et justifiée (industriel/cobot/AMR).
- ☐ Le cadre normatif applicable est identifié (ISO 10218, ISO/TS 15066, etc.).
- ☐ Au moins 4 exigences de sécurité sont prévues.
- ☐ Le coût total est découpé en au moins 8 lignes (robot + intégration + sécurité + formation + maintenance).
- ☐ Les gains sont multi-dimensionnels (productivité + qualité + ergonomie).
- ☐ Le payback est calculé et positionné dans une fourchette défendable.
- ☐ La dimension RH (redéploiement, formation, dialogue social) est traitée explicitement.

Si l'une de ces cases reste vide, reprenez l'étape correspondante
avant de présenter le dossier.
