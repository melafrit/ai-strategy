Elle est volontairement séparée du contenu pédagogique destiné aux apprenants : ce dernier sera publié dans `src/content/` à partir de la Phase 4 et alimentera le site web.

## 📝 Conventions de documentation

- **Langue de la documentation projet** : français (langue de travail principale).
- **Langue du contenu pédagogique publié** : trilingue FR/EN/AR.
- **Format** : Markdown standard, avec usage parcimonieux des extensions GitHub (tableaux, listes de tâches, blocs de code, callouts via `> [!NOTE]`).
- **Diagrammes** : [Mermaid](https://mermaid.js.org/) pour la cohérence avec le rendu GitHub natif.
- **Versionnement** : toute modification structurante des documents de cadrage donne lieu à un commit `docs(cadrage):` dédié.
